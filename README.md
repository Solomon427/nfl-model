# nfl-model

PIC16B NFL project
This project analyzes the value of NFL draft picks by comparing player performance to rookie contract cost. 
Using historical draft, contract, and performance data, we study which draft rounds or pick ranges tend to provide the best performance per dollar.

The repository is organized into three main components:
- Data Cleaning Notebook
- Machine Learning Notebook
- Fine Tuning Notebook

The results directory contains all final outputs from the pipeline:
- Tables
- Figures

The src directory contains modular Python functions used throughout the pipeline:
- data
- models
- fine tuning
- utils
